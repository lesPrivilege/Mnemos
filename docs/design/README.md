## 一、产品判断

**Mnemos 保持随身学习工具的体量，把阅读、摘录、制卡、练习与复习之间的连续性做成设计样板。** 丰富度放在真实对象与操作中，不扩成通用知识工作台，也不另造一套与产品分离的演示控件。

Courtwork 负责更复杂的工作治理；Mnemos 可以承担交互试验的轻载体：同一对象如何被找到、拿起、展开、比较、修改、保存、撤销，再回到来源。允许为这些 grammar 增加小型本地能力，允许探索更强的层次、手势与 motion。每项实验都必须有能够独立完成的学习任务。

整体基调是**冷灰纸面、石墨工具、砖红批点，安静的阅读与明确的动作形成反差**。古籍版式的纪律保留，仿古装饰不入场；“高级”不依赖把字号做小、把动作藏深、把所有内容装进卡片。

一级入口继续是“今日／资料／活动”。详情与会话继续承接其下的阅读、题目、闪卡对象。Design 样板独立启动，不占第四个一级入口。

已有产品与代码依据：来源索引 MN-01、MN-03、MN-06。本文其余“应／采用／增加”是本轮方案，尚未表示应用实现。

## 二、视觉方向

### 2.1 Dystopia 的来源与落点

Courtwork 的 Dystopia 已登记为独立候选外观，cold ash / graphite 的数值来源仍待冻结；当前应用默认是 lead-gray。不能把当前 `app/web/styles.css` 整块复制后称作 Dystopia。

Mnemos 自己的 `src/styles/tokens.css` 已保留更确定的 Dystopia 谱系：冷灰纸、石墨与来自 `#B0392B` 的砖红，实际消费者使用 OKLCH。首轮直接沿这份底本建立明暗 specimen，吸收 CW 的色彩职责隔离，不再发明一套近似 hex。

| 角色 | Mnemos 已有 token / 浅色底本 | 本轮用途 |
|---|---|---|
| 纸面 | `--bg: oklch(97.6% 0.002 240)` | 阅读与应用底盘 |
| 对象面 | `--bg-card: oklch(100% 0 0)` | 卡面、必要的浮出对象 |
| 次层 | `--bg-raised: oklch(95.4% 0.003 240)` | 局部工具、次级区域 |
| 主墨 | `--ink: oklch(24% 0.006 240)` | 正文与主操作 |
| 人的痕迹 | `--accent: oklch(51.5% 0.155 30)` | 摘录边记、当前位置、已作评价的标记 |
| 有后果的危险 | `--danger-critical` | 删除、重置，不与 accent 合并 |

色板注释中的 `#F4F5F6 / #DDE1E4 / #565C5F / #2A2D2E / #B0392B` 只登记谱系，不充当以上 OKLCH 的精确换算。深色沿现有暗宗读取，不按浅色 hex 反转生成。

**继承的是颜色职责分离，不是 CW 的业务词义。** CW 的 Review 是工作接受语义；Mnemos 的 review 是学习复习。不可把 CW 的批准、权限或待审状态搬进 Mnemos。红色不成为通用按钮底、热图强度、成功态或键盘焦点。

### 2.2 版式与材料

UI 宋、内容仿宋／宋、Times 展示与真实数据 mono 的既有字轨先保留；阅读文字不参与缩放形变。细部先修字号、基线、行高与点击区，再讨论更换字体。

“今日”是一个明确的继续入口加紧凑待办行；“资料”是有秩序的书目，而非三等分功能卡；阅读以正文为主体；闪卡本身可以有对象感。宽屏新增原文与摘录并置的 specimen，正文栏长保持上限，新增空间给关系而不是把文字拉宽。

常驻内容保持实底、无影。首先用边界、遮挡、留白和前后位置建立层次。触发中的选区工具条、拖拽对象与短暂浮层可登记局部材质实验；不是全局开放 glass、阴影和弹簧。普通状态切换不采用 bounce。

同一 grammar 共享图标比例、动作位置、按压反馈与恢复路径。少数新领域符号从 Mnemos 现有 SVG 几何语言生长；CW 品牌包移植的是源码到样板的工艺，不是把 Courtwork 的标志换个名字。

### 2.3 两个使用面，一套组件

**学习面**服务长时间使用，反馈短、稳定、可中断。**样板面**提供同一组件的可重置场景、状态选择、慢速回放与去动效对照；它可以展示更强的转场与宽屏并置，但不建立另一套按钮、卡片与浮层。

样板说明与状态标签属于旁侧检验控制，不进入日常产品文案。演示数据在样板页明确标明；不伪装成用户历史、真实学习成效或未实现的模型能力。

## 三、三个代表场景

### A. 从原文长出一张卡片

打开一篇有目录与公式的文章。选中一段文字，工具条贴着选区出现；手指与系统选择柄仍能正常工作。先保存摘录，正文位置不被抢走。点“制成卡片”，选区的身份沿转场保留，问题与答案在局部编辑面展开；用户补写问题后保存。

保存后，新卡片进入本次学习托盘，原文旁留下一个可返回的标记。完成一次复习后，点“查看原文”，准确回到对应段落；关闭原文，回到刚才的卡片与答案态。

**样板重点：** contextual toolbar、局部编辑面、对象连续转场、source link、返回位置、取消与撤销。

现有 Reader 已有高亮、笔记字段、制卡预填与来源文字；本轮新增的是局部制卡与稳定来源关联，不是再造内容生成器。现有代码把来源标题拼进答案文本，不能据此认定精确回跳已成立（MN-07、MN-08）。

### B. 一次判断，有清楚的落点

卡片正面呈现一个问题，主操作是“显示答案”。展开答案时，题干留在视线里；四档评价沿同一条评价轨出现。四个评价按钮仍然一触即评，既有快捷键不增加确认步骤。触屏可另试拖动预选通道：松手只是选择，再显式提交才记入复习；它不替代高频的一步评分路径。

提交后，刚才的卡片退出、下一张接续，评价成为短暂回执。点“撤销”，回到原卡与已展开答案，恢复真实调度与本次会话状态，而非只倒放动画。下一张准备好不等待动效播放完。

**样板重点：** reveal、离散评价轨、手势预选、原位回执、撤销、连续操作与触觉反馈。

质量值必须沿用现有 `1 / 2 / 4 / 5` 与 learning/requeue 逻辑。不得以一个连续的“熟练度百分比”替代四档，也不在未见答案时写入评价（MN-10）。

### C. 把今天拿在手里

在资料中搜索、筛选或多选文档、卡组与题集，加入“本次学习”。托盘收起时只显示内容摘要，展开后可以排序、移除、继续；重新进入时保留本次的组织，而不改变 SM-2 到期日。

活动页选择某一天或一个范围，热图与当日明细围绕同一个筛选条件联动。点击一条已记录活动，回到相应材料；缺失材料给出可理解的断链落点。活动图表现“做过什么”，不包装成“记住了多少”。

**样板重点：** search lens、多选、拖拽排序、可折叠托盘、日期 brush、图表与明细联动、来源导航。

## 四、功能预算

| 能力 | 最小新增 | 边界 |
|---|---|---|
| 来源回跳 | 文档／高亮／题目到卡片的类型化关联，保留原文摘句与定位信息 | 不引图数据库，不以全文近似搜索冒充精确命中 |
| 本次学习托盘 | 类型化对象引用、顺序、继续点 | 不替换复习调度器，不增加云端同步 |
| 返回轨迹 | 会话内 route、对象、滚动锚点、焦点与展开状态 | 不建长期行为画像，不在备份中强塞所有临时 UI 状态 |
| 活动范围联动 | 当前日志的日期筛选、明细与材料回跳 | 不虚构 retention、掌握率、预测学习收益 |
| 样板场景 | 独立入口、合成 fixture、重置与偏好对照 | 不启动提醒、自动备份，不改真实数据 |

其他新控件只有在上述场景遇到确切问题时进入。可以探索阅读参数 scrubber、双栏比较和导入预检；不为填满组件目录增加权限系统、聊天框、AI 等待动画、无限画布、关系网或任务管理后端。

## 五、旧规范的递修

用户此次授权增加表现力，应在 `design-collation.md` 记录为新的范围裁决，而非绕过旧文档与 collate。

| 既有规范 | 本轮处理 |
|---|---|
| 无应用内 LLM、外部制作、local-first | 保留 |
| 三入口、现代中文、底本单源、可访问操作 | 保留 |
| 每屏至多一处入场 | 延展为“同一时刻一个主运动组”；一张对象跨多个层的连续变形算一个组 |
| iPad 横向不编排 | 先为样板开放原文／摘录并置；产品推广按独立验收落账 |
| 全书无影 | 日常内容保留；仅允许 transient/drag specimen 做实底无影与局部抬升对照 |
| 弹簧只用于手势 | 保留；跟手与松手收敛可试验，状态或数据变化不 bounce |
| 不动 width/height | 保留布局稳定原则；允许 transform-based FLIP，但文字、公式不能被拉伸 |
| 样板无业务之外事实 | 保留；所有状态先有真实 owner 或明确 fixture |

先让第一场景完成，再推广已成立的语法；不同时给三个模块分别设计三套语言。

## 六、交付组织

仓库只增加一个轻量 Design 入口及本包三份工作文档、机器来源账；实际实现按 MX-00…MX-06 串行。MX-01 与 MX-02 构成首个可玩节点。每轮附同一 fixture 的明暗、正常／减弱动态、返回与错误状态证据。

后续回流 Courtwork 的是经过使用检验的 grammar、motion recipe、状态矩阵与实现成本；不把 Mnemos 的学习模型、移动端导航、书目隐喻或 JSX 实现整包塞回 CW。
