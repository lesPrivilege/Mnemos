## 一、宗

Mnemos 以版本学治一部随身递修之书：形取古籍刻本之版式纪律——界行有等、朱唯人裁、静为常、记号携义、牌记随行；交互与无障碍从当代公法（WCAG、平台惯例）；拒 SaaS 坊刻默认，亦拒仿古皮肤。

宗之三推论：

1. **产品即书，而书不自言**。卡组是册，卡片是叶，复习是批点，统计是校勘记——此对应治版式语法与工程秩序，**不入 UX 文字**：界面文案从平实现代中文（「待复习」「开始复习」），文本本身不承载设计语言；版本学词汇止于文档、流程与 token 层。设计语言经由形显现，文字层至多在字体选型上取刻本/写本谱系（拉丁文同理）（主令裁定，2026-07-24，记-06）。
2. **递修不换皮**。一系之内累印递修；版本记录、校勘记、判例即品味之证。分布中位每移一步，本项目以讳表回应，不以重刻回应。
3. **新功能自例而生**。任何新页面、新组件先问四件：声部预算何在、行款是否可著录、记号携何义、态是否俱全。答不出者不开工。

### 临文不讳登记

被禁形在用者，据各一句：

- **内容衬线（宋体）**：内容字轨（卡面、答案、阅读正文、册名）之定制，据「内容 vs chrome」字轨政策（判例三），非衬线 hero 跟风。
- **红系 accent（砖红 `#af3a2c`）**：反解自 Dystopia 色板 `#B0392B`，鈐印之义；底盘为中性灰阶 hue 240，全书唯此一处有彩之常驻记号，非暖调品味默认（R2 换刻，记-25；铜 `#B86A30` 已退役）。
- **backdrop blur**：唯 `--surface-chrome-*` 所辖的真正局部 overlay（现行为详情 `FloatingBar`），非 L0 一级目录、顶栏、内容面或玻璃拟态整面；透明度／高对比偏好退为实底与强边界。L0 目录附着于应用壳，不以悬浮卡形呈现（记-45）。
- **「AI」入文案（AI 制作指南页及 Import 三入口）**：家5 所禁是界面形暗示**应用内** LLM 调用（生成中动画、AI 徽章、魔法棒 icon）；此页职能恰是把材料带去外部 AI 再把产出带回，字面明言「复制给任意 AI」正是划清内外边界，避讳反致语义不明。页面无任何生成态记号（记-36）。

## 三、善本著录

三部入藏，各过足、精、旧三义；所移者为法，不为貌。

### 善本一 · 古籍刻本版式传统（形之谱系）

- **足**：宋元明清历代刻本全态存世，版式语法（行款、界行、版心、牌记、朱墨套印）有完整著录学。**精**：行款可一句著录（「半叶十行，行二十字，白口，左右双边」）即工艺可审计之极致。**旧**：千年递修，流传有绪。
- **可移何法**：线之两等语法（文武边栏/乌丝栏 → 主界/次界）；版面一句著录法（→ 行款著录语）；朱墨分声（色即声部，朱唯批点）；牌记（构建出处随行世件）；记号必携义（鱼尾为折叠定位而设，不为饰）。
- **限度**：无交互之学。链接、焦点、动效、无障碍一律从今之公法，不硬造古色古名（刊例移译三则之二）。

### 善本二 · Andy Matuschak 之 mnemonic medium（物之谱系）

- **足**：notes 与 essays 全态公开，含未完成态之诚实标注。**精**：站可 view-source，Quantum Country 之嵌入式复习工艺有公开论文与实现可考。**旧**：2019 年起递修，流传有绪。
- **可移何法**：界面即论点，零营销声；复习生于阅读语境（Mnemos 之「高亮→闪卡」「错题→闪卡」闭环与此同宗，此善本证其正统）；间隔重复是阅读的延伸而非游戏化的宿主。
- **限度**：其媒介为长文网页，Mnemos 为移动工具；密度与手势语法不移。

### 善本三 · midday.ai（数据纪律）

- **足/精**：据 anti-ai-slop-kit `03-范例档案/06` 之 2026 年 DOM/CSS 一手拆解：数据区绝对静止（「数据不应晃动」）、细灰线纵横成蓝图矩阵、语义色只司财务正负。**旧**：2023 年起，递修年浅，降半格用——取纪律，不取签名。
- **可移何法**：统计与列表之区静止、矩阵化、色预算赤字。
- **不移**：衬线大标（中文小字号衬线于低 DPI 有笔画残缺之弊，kit 04/08 已证）；零圆角倾向（Mnemos 圆角止于 10px，不必更狠）。
- **旁注 Linear**（同拆解）：瞬时反馈纪律（过渡 ~0.1s、Hover 之外无浮躁动效）可参；紫 accent 与暗面语汇不移。

### 形制与外部 skill 准入

- **圆角职司**：底本仅有 `--r-sm`／`--r-md`／`--r-lg`／`--r-xl` 四档，即 `2/4/6/10px`；2px 司细线、轨与微小标记，4px 司 Button、字段、题卡／闪卡等标准交互对象，6px 司 popover、菜单与较大的独立紧凑对象，10px 只司已有的大型局部 sheet／overlay 外轮廓。四档是组件语义的边界工具，不是全局装饰层级；附着面、连续分节与 L0 目录外壳取 0，内部控件仍按自身职司取角。新值、全局重映射或把 10px 当普通页面容器默认值，均须复议；正圆与胶囊仍属形状习语，不计入圆角档。
- **影与材质**：常态无投影（`--shadow-sm/md/lg` 均为 `none`）。真正局部 overlay 才可采用 `--surface-chrome-*` 的半透明／blur，并须在无 blur、`prefers-reduced-transparency` 与高对比偏好下仍以实底和边界成立；任何 overlay 投影另案论证，不随本轮引入。整面玻璃、半透明 L0 目录与内容面一律不采。
- **动效与无障碍**：动效只解释状态或按压反馈，不改布局；L0 高频导航只准 `--motion-quick` 的按压／色变，不设移动 indicator、弹簧、bounce、形变图标或页间滑屏。导航用真实链接与 `aria-current`，不是把目录伪作切换钮；可操作目标至少 `44px`，L0 项至少 `48px`，safe area、焦点、键盘／读屏径路与 reduced-motion 必须各自验收。
- **外部 skill 准入**：社区、Apple、OJO、Morphicons 等只作可核验的研究证据或受限工艺工具，不取得 Mnemos 设计权。每次调用须绑定一个组件或状态，交付来源、今义、状态图、motion／无障碍／偏好降级与舍弃项；不得自行新增色板、字体、圆角、阴影、整面材质或 vendor shell。实施前后均按本底本、真实 selector、测试与书影复核，未能说明「帮助用户理解什么」者不入行世。

## 五、行款著录语

> 手机单栏，栏宽止于 44em；正文（内容字轨）行长约 20–24 字，行高 1.7；字阶据实九档（`--text-2xs`…`--text-4xl`，rem 起，`--text-xl`＝1rem 为内容阅读锚），低端精细、层级跳档不小于 1.2（正文 13 → 题 19 ＝1.46），展示号另走流体 clamp（记-16）；线两等——主界 `--border`、次界 `--border-soft`，`--border-strong` 唯交互强调，不入结构；圆角四档止于 10px（正圆与胶囊属形状习语，不计档）；全书无影；彩司语义、朱唯人裁、主操作用墨；数据之区静止，动为仪式，每屏至多一处入场，动效属性守 transform/opacity 与非布局色变（width/height/位移属性不得动）。

**iPad 竖向一款（记-21）**：外框止于 `--col-read` 加天地（`--gutter-wide` 48）；L0/L1 内容守 `--col-list` 480，会话守 `--col-session` 560，阅读守 `--col-read` 680；chrome 随外框而其内容与栏首对齐。横向不做编排（拒准同档），仅保不破版。

此语为一切版面之对校基准；实测值（视口 390×844 基准）由死校丈量并记入对照表。版面著录不出此语者，改版面，不改语——改语走复议（刊例第卅八条）。

### 字轨四声（2026-07-24 主令两度递修，现行为记-10 之制；轴存族易）

## 七、声部登记

色即声部，各有其司；此表为语义预算之全部，扩声部走复议。

| 声部 | token | 司 |
|---|---|---|
| 墨 | `--ink` 系 | 内容与主操作（主按钮墨底纸字）；熟练度序列亦归此阶——新 `--ink-4` → 中 `--ink-3` → 稳 `--ink` |
| 砖红（朱之职） | `--accent` 系 | 鈐印身份（wordmark、icon）、当前位置（due 数、进度、streak、active tab、焦点环）、人裁之痕（收藏、高亮标记）（R2 换刻，记-25；铜已退役） |
| 墨阶之错 | `--danger` 系 | **告知类之错**：错误提示、错题标记、顽固卡、弱卡。既退墨阶，识别须配非色线索——2px 重描边＋恒在图标＋明确动词，缺一即讹（记-25） |
| 真红 | `--danger-critical` 系 | **有后果之动作**：重来（重置间隔）、删除（毁数据）。此声部唯此二义，扩张走复议（记-25） |
| 赭黄 | `--rate-hard` / `--warn` 系 | 困难；警示 |
| 绿 | `--good` 系 | 容易、对、阅读模块 |
| 青 | `--teal` 系 | 唯活动页跨模块对比图之练习系（已定，记-05；此外任何取用皆讹） |
| 紫 | `--plum` | 无司——退役候选（刊例第四十五条，入账不径删） |
| 代码七色 | `--tk-*` | 唯代码语法，不入 chrome |

**danger 之分声判准（记-25）**：按「有无后果」划线，不按屏之轻重划线。用户将要失去或刚刚失去某物者取真红；只是被告知某处不对者取墨阶。此判准可一句陈述，故可入簿；「这屏不重要故不给色」不可陈述，故不取。

旁注：科目色相（`SUBJECT_HUE`）为**数据身份轴**——由名称派生、只作识别，不承语义，不入上表预算；现存唯一真消费者为 Settings 之科目行（`src/quiz/lib/subjectMeta.js`）。列表行之 `.deck-spine` 四档（`h0–h3`）於 R2 退役：CSS 里四档同解析为 `--ink-2`，四色早已无别，是名存实亡之轴（记-31）。

## 九、门禁指认（死校）

工具：`scripts/collate/`，命令 `npm run collate`，并入 `npm run check`。四门，各有阴性对照（`--self-test` 断言每门能红）：

1. **对校·底本单源**：`src/` 内（除 `tokens.css`）不得有色字面量（oklch/hex/rgb）、圆角 px、cubic-bezier、transition/animation 时长字面量。
2. **避讳·字面**：渐变文字、紫蓝渐变、玻璃拟态、bounce/elastic 曲线（过冲 cubic-bezier）、width/height/padding/margin 之 transition/animation。
3. **对校·对比度**：解析底本，正文/次文/三级文对底面、语义色对其 soft 底，两主题逐对算 WCAG，AA 线下者红；产出 `docs/contrast-table.md`（影刻，携牌记）——此即 Phase B 遗留 Rider 1 之交付。**R2 补入四类落点对**（记-25）：`ink-3`／`accent` 对 `bg-raised`（旧门只校 `/bg` 与 `/bg-card` 两底，此落点漏校而两纸皆曾在 4.4x 徘徊）、`danger-critical` 三对、`bg` 对 `danger-critical`（语义底纸字——恒白在暗纸只 2.98）；INFO 补 `ink` 对 `ink-4`（熟练度计之充填对轨）。**门之限度须知**：此门校 token 对 token，不校渲染落点——`opacity` 混算、token 用作从未配对之底、四级墨排字，皆在门外。凡新落点必手算後入门，不得以「门绿」代替。
4. **牌记完整**：构建产物含版本与提交哈希（`__MNEMOS_BUILD__`），Settings 牌记面消费之。

死校之门只报离合，不定是非；不可判定者（态之有无横查、层级倒序、衍文删除校验）归活校，记入校勘记簿。

独立样板可用原文／摘录宽屏并置；手机仍单栏。动效预算按同一时刻一个主运动组核对，文字不缩放。首单实底无影，局部材质与手势实验另案登记；该范围不自动推广至生产页面。数值唯一底本仍为 tokens.css。
