# Mnemos 刊例采用件

**性质** 项目槽位文件。权威条文在 `~/Projects/Deswrit kit/03-刊例.md`（定本 2026-07-24），本文件不抄条文，只填刊例许项目自填之四槽——宗、家讳、底本实体、门禁——并载善本著录、行款著录语、记号谱、声部登记与预留槽位。条文与本文件冲突时，从条文。

**牌记** 立于 2026-07-24，v1.4.0 之后、v1.5.0 刊例采用轮之首。所据：deswrit-kit 定本 2026-07-24；anti-ai-slop-kit 定稿 2026-07-16（史料）。裁定过程见 `docs/design-collation.md`。

**读法** 界面与站点工作开工前读刊例第三编至第七编；中文书面输出从 `deswrit-kit/01-凡例.md`。本项目每轮交付前过刊例附录乙审书状，雠由非实施 agent 担任。

## 一、宗

Mnemos 以版本学治一部随身递修之书：形取古籍刻本之版式纪律——界行有等、朱唯人裁、静为常、记号携义、牌记随行；交互与无障碍从当代公法（WCAG、平台惯例）；拒 SaaS 坊刻默认，亦拒仿古皮肤。

宗之三推论：

1. **产品即书，而书不自言**。卡组是册，卡片是叶，复习是批点，统计是校勘记——此对应治版式语法与工程秩序，**不入 UX 文字**：界面文案从平实现代中文（「待复习」「开始复习」），文本本身不承载设计语言；版本学词汇止于文档、流程与 token 层。设计语言经由形显现，文字层至多在字体选型上取刻本/写本谱系（拉丁文同理）（主令裁定，2026-07-24，记-06）。
2. **递修不换皮**。一系之内累印递修；版本记录、校勘记、判例即品味之证。分布中位每移一步，本项目以讳表回应，不以重刻回应。
3. **新功能自例而生**。任何新页面、新组件先问四件：声部预算何在、行款是否可著录、记号携何义、态是否俱全。答不出者不开工。

### 临文不讳登记

被禁形在用者，据各一句：

- **内容衬线（宋体）**：内容字轨（卡面、答案、阅读正文、册名）之定制，据「内容 vs chrome」字轨政策（判例三），非衬线 hero 跟风。
- **暖色 accent（铜 `#B86A30`）**：直取品牌 icon 实色，鈐印之义，非奶油品味默认；底盘为冷中性 hue 250，暖唯此一处。
- **backdrop blur**：唯 `--surface-chrome-*` 一处（底部 tab bar 类 chrome），非玻璃拟态整面。

## 三、善本著录

三部入藏，各过足、精、旧三义；所移者为法，不为貌。

### 善本一 · 古籍刻本版式传统（形之谱系）

- **足**：宋元明清历代刻本全态存世，版式语法（行款、界行、版心、牌记、朱墨套印）有完整著录学。**精**：行款可一句著录（「半叶十行，行二十字，白口，左右双边」）即工艺可审计之极致。**旧**：千年递修，流传有绪。
- **可移何法**：线之两等语法（文武边栏/乌丝栏 → 主界/次界）；版面一句著录法（→ 行款著录语）；朱墨分声（色即声部，朱唯批点）；牌记（构建出处随行世件）；记号必携义（鱼尾为折叠定位而设，不为饰）。
- **限度**：无交互之学。链接、焦点、动效、无障碍一律从今之公法，不硬造古色古名（刊例移译三则之二）。

### 善本二 · Andy Matuschak 之 mnemonic medium（物之谱系）

- **足**：notes 与 essays 全态公开，含未完成态之诚实标注。**精**：站可 view-source，Quantum Country 之嵌入式复习工艺有公开论文与实现可考。**旧**：2019 年起递修，流传有绪。
- **可移何法**：界面即论点，零营销声；复习生于阅读语境（Mnemos 之「高亮→闪卡」「错题→闪卡」闭环与此同宗，此善本证其正统）；间隔重复是阅读的延伸而非游戏化的宿主。
- **限度**：其媒介为长文网页，Mnemos 为移动工具；密度与手势语法不移。

### 善本三 · midday.ai（数据纪律）

- **足/精**：据 anti-ai-slop-kit `03-范例档案/06` 之 2026 年 DOM/CSS 一手拆解：数据区绝对静止（「数据不应晃动」）、细灰线纵横成蓝图矩阵、语义色只司财务正负。**旧**：2023 年起，递修年浅，降半格用——取纪律，不取签名。
- **可移何法**：统计与列表之区静止、矩阵化、色预算赤字。
- **不移**：衬线大标（中文小字号衬线于低 DPI 有笔画残缺之弊，kit 04/08 已证）；零圆角倾向（Mnemos 圆角止于 10px，不必更狠）。
- **旁注 Linear**（同拆解）：瞬时反馈纪律（过渡 ~0.1s、Hover 之外无浮躁动效）可参；紫 accent 与暗面语汇不移。

- **影刻清单**（皆非权威，须署牌记）：
  - `docs/design-tokens.md` — 曾为约束单，已漂移（记暖调 hue 90、有影、宽圆角；底本现为冷中性 hue 250、无影、窄圆角）。本轮降格为指针件，史料见 git 史（判例七）。
  - `design/handoff/*.html`、`design/archive/*` — Phase B 及更早原型，归档史料，无约束力；现行文本引之只可引称。
  - `assets/screenshots/polished/*.png`、`docs/index.html` — 书影，行世须携著录项（版本、提交哈希、视口、主题）。
- **缺口现状**（v1.5.0 写定时）：时长字面量已清零归源（余三处手势域内联，基线在册）；`--teal` 已定司、`--plum` 退役候选存账（记-05）；type/spacing 两档 scale 仍未接线——列 roadmap Phase 4.7 派发单元，非本轮遗漏。

## 五、行款著录语

> 手机单栏，栏宽止于 44em；正文（内容字轨）行长约 20–24 字，行高 1.7；字阶 1.2 律七档，级差不小于 1.2；线两等——主界 `--border`、次界 `--border-soft`，`--border-strong` 唯交互强调，不入结构；圆角四档止于 10px；全书无影；彩司语义、朱唯人裁、主操作用墨；数据之区静止，动为仪式，每屏至多一处入场。

此语为一切版面之对校基准；实测值（视口 390×844 基准）由死校丈量并记入对照表。版面著录不出此语者，改版面，不改语——改语走复议（刊例第卅八条）。

### 字轨四声（2026-07-24 主令两度递修，现行为记-10 之制；轴存族易）

| 轨 | 族 | 司 |
|---|---|---|
| 器（UI 层） | 多字重宋（Noto Serif SC 400–700），UI 拉丁与数字前置 Times；栈尾收 serif 泛族，黑体无落点 | chrome 全体：题、多级路由、按钮、标签、页签、行名、提示、meta——层级唯字重字号墨色 |
| 文（内容层） | 朱雀仿宋（常用级子集）；罕字回退 FangSong/STFangsong/宋 | 内容正文：卡面、答文、阅读正文、题干、选项、解析、编辑区。**同版异纸**：仿宋 ⇄ 宋切换入口，root class 切于底本层，组件零分支 |
| 文中之题 | 宋之重（题宋文仿） | 内容视图内的标题与强调（markdown h*、strong） |
| 展示 | Times 系，`lnum`/`tnum` | wordmark 与展示大数字 |
| 数据 | JetBrains Mono；数学公式 KaTeX 自字体 | 唯真数据与代码、公式——terminal 声不动，免割裂 |

判准：UI 层与内容层字体各自独立不耦合；全渲染路径无黑体暴露（含 mono 之 CJK 回退）；伪粗伪斜不施（`font-synthesis: none`）。

朱雀仿宋著录：OFL 开源，单字重，v0.212（TrionesType/zhuque），OFL.txt 随藏；治正文故子集取常用级（频率表推导），罕字逐级回退，回退可见度入真机验证批。

## 九、门禁指认（死校）

工具：`scripts/collate/`，命令 `npm run collate`，并入 `npm run check`。四门，各有阴性对照（`--self-test` 断言每门能红）：

1. **对校·底本单源**：`src/` 内（除 `tokens.css`）不得有色字面量（oklch/hex/rgb）、圆角 px、cubic-bezier、transition/animation 时长字面量。
2. **避讳·字面**：渐变文字、紫蓝渐变、玻璃拟态、bounce/elastic 曲线（过冲 cubic-bezier）、width/height/padding/margin 之 transition/animation。
3. **对校·对比度**：解析底本，正文/次文/三级文对底面、语义色对其 soft 底，两主题逐对算 WCAG，AA 线下者红；产出 `docs/contrast-table.md`（影刻，携牌记）——此即 Phase B 遗留 Rider 1 之交付。
4. **牌记完整**：构建产物含版本与提交哈希（`__MNEMOS_BUILD__`），Settings 牌记面消费之。

死校之门只报离合，不定是非；不可判定者（态之有无横查、层级倒序、衍文删除校验）归活校，记入校勘记簿。
