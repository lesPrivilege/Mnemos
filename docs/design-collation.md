**性质** 常设簿册。活校之改必留记（刊例第卅四条）；裁定「不采」与「采」同等入档（第卅五条）；同题三见且判准已稳者，自校勘记升格为判例（第廿一条）。本文件与 `docs/design-kanli.md` 同为本项目设计常法；条文权威在 `~/Projects/Deswrit kit/03-刊例.md`。

## 判例册

### 判例一 · 顶栏不透明

- **裁定**：`.topbar` 背景取不透明 `--bg`，只采 chrome blur 之半径；不用 `--surface-chrome-bg`。
- **据**：token 系列第二笔实测——真实内容滚动于 sticky 顶栏之下，半透明底可见渗色。
- **既判力**：一切「顶栏也改半透明以配 FloatingBar」之提案。
- **复议门槛**：以真实内容重测并出书影为证，不得以「理论上可行」复议。

### 判例二 · 双语标签减法

- **裁定**：`中文 · ENGLISH` 装饰性双语标签全数删除（fe6c698：52 处审计，0 保留；另 14 处英文 aria-label 中文化）。
- **判准**：英文半有独立信息或节奏者留，装饰性回声者删；存疑从删。
- **既判力**：任何单条标签之重引须附该标签专属的书面理由。

### 判例三 · 字轨

- **裁定**：字分四轨——内容宋（`--font-zh`）、chrome 黑（`--font-ui`，不分文种）、展示衬线（`--font-disp`，唯 wordmark 与展示数字）、mono（`--font-mono`，唯真数据：数、日期、计数、百分比、代码、路径）（d326a9e，收尾 7f23bdb：96 处审计，53 留 mono、43 转轨）。
- **判准**：紧邻数字的全大写类目标签是描述数据的 chrome，不是数据——标签转轨，数字留 mono。
- **既判力**：新页面不得因「文字是中文」而选 `--font-zh`；内容/chrome 之别唯一有效。

### 判例四 · 朱唯人裁（accent 声部）

- **裁定**：accent 退出评分行、错题、警示等一切语义场景；只司鈐印身份、当前位置（due、进度、streak、active tab）与人裁之痕（v1.4.0）。
- **既判力**：accent 不作按钮底色、不作装饰块、不入语义警示；声部扩张走复议。

### 判例五 · 会话直排

- **裁定**：L2 复习/练习会话内容直排 `--bg`，去卡套卡；「答」朱印替 ANSWER 角标（v1.4.0）。
- **既判力**：会话类全屏页不引入容器卡；卡唯用于「叶」义成立处。

### 判例六 · 大轮必拆笔

- **裁定**：跨页面重定调不得单笔提交。M1b 首笔（57177e9）单笔回迁，致三页遗漏、越界 CTA、tab bar 超厚近三成，事后 9 笔修复方齐。
- **判准**：一轮触及三页以上者，按页或按母题拆笔，中途至少一次独立 review 检查点。
- **既判力**：本轮刻版递修适用。

### 判例七 · 影刻漂移即讹

- **裁定**：`docs/design-tokens.md` 与 `design/handoff/phase-b-full.html`（== `docs/index.html`，逐字节同）所记为 Phase B 暖调值（bg hue 90、accent oklch 38、radii 4–16px、有影），底本已于 eb8d39d 转冷中性（bg hue 250、accent `#B86A30`、radii 2–10px、全零影）。影刻与底本不同步而行世，以讹论：design-tokens.md 降格为指针件；design/ 各 HTML 归档为史料；另立漂移预防——影刻必署非权威与牌记，死校核牌记。
- **既判力**：凡由底本派生之文档、原型、书影，无牌记者不入验收。

### 记 2026-07-25-23 · 结构改法：级由变量择，消费唯一

雠差量复核判**仍不可写定**，且三条不刊里两条是**我修出来的新回归**——根因一处：为排除幕布，我给通用收束添了一个 `:not(.confirm-backdrop)`，特异性由 0-2-0 升至 0-3-0，而两条解除仍是 0-2-0，遂被**无条件**压过。后果：阅读正文被摁回 480（我却只测了顶栏公式，未测正文落点，故自测通过而实际未修）；活动页从「仅旧 WebView 裁切」变成**任何浏览器都裁切**——比修前更劣。会话页那条收束又漏排幕布，致删除确认时幕仅 560 且贴左，大半视口不暗。

### 记 2026-07-25-21 · 竖向缩放谱（主令 M2 立项，首实）

- **病何**（实测）：`#root` 于 `≥720 且竖向` 一律放满，iPad 竖屏单栏横铺 768pt——列表行之名与其操作分踞两端遥望（「learning-methods」与「练习 →」相隔半屏）、分隔线长如表格、数字与其标签失统。此即主令所指「不破版而未编排」。
- **谱**（入底本）：`--col-list 480` / `--col-session 560` / `--col-read 680` / `--gutter-wide 48`。**一栏之宽有度，余宽让给天地，不让行拉长**；手机既定行款不动，宽屏只加白。
- **架构**：`#root` 只给外框（取最宽者 `--col-read` 加天地）与居中，**各级内容各守其度**；chrome（顶栏、底栏）随外框，其内容以 `max(sp-7, (100% - col-list)/2)` 内缩与栏首对齐——上下 chrome 同度方统。两处以 `:has()` 声明式解除：活动页（仪表盘双栏须整幅，其自有 1120 上限）、阅读页（守自身 measure 680）。旧 WebView 无 `:has()` 则退化为收窄，不破。
- **实测**（768×1024）：外框 768、顶栏通幅内缩 144、列表栏 480、阅读 measure 680、活动双栏完整；手机 375 处外框 375、顶栏 18px，未受牵连。
- **一坑记之**：谱初写于 `@layer base` 内，`.topbar` 之内缩被**未分层**的原规则吞掉（层内优先级低于未分层）——移出该层方效。凡欲覆盖既有未分层规则者，不得置于 `@layer` 内。
- **顺手修**：Reader 之 `missing` 态于 id 变更时不复位，由不存在之文档转入存在者仍滞留「未找到」——记-14 补断链态时引入，实测抓出，已于 effect 首行复位。

### 记 2026-07-25-20 · 终判与宜酌尽补（字阶轮写定）
