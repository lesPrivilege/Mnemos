# 校勘记簿 · 判例册

**性质** 常设簿册。活校之改必留记（刊例第卅四条）；裁定「不采」与「采」同等入档（第卅五条）；同题三见且判准已稳者，自校勘记升格为判例（第廿一条）。本文件与 `docs/design-kanli.md` 同为本项目设计常法；条文权威在 `~/Projects/Deswrit kit/03-刊例.md`。

记之格式：**改何 · 据何 · 判准 · 证据**。判例另加**既判力范围**与**复议门槛**。

## 判例册

### 判例一 · 顶栏不透明

- **裁定**：`.topbar` 背景取不透明 `--bg`，只采 chrome blur 之半径；不用 `--surface-chrome-bg`。
- **据**：token 系列第二笔实测——真实内容滚动于 sticky 顶栏之下，半透明底可见渗色。
- **既判力**：一切「顶栏也改半透明以配 FloatingBar」之提案。
- **复议门槛**：以真实内容重测并出书影为证，不得以「理论上可行」复议。

### 判例二 · 双语标签减法

- **裁定**：`中文 · ENGLISH` 装饰性双语标签全数删除（fe6c698：52 处审计，0 保留；另 14 处英文 aria-label 中文化）。
- **判准**：英文半有独立信息或节奏者留，装饰性回声者删；存疑从删。
- **既判力**：任何单条标签之重引须附该标签专属的书面理由。

### 判例三 · 字轨

- **裁定**：字分四轨——内容宋（`--font-zh`）、chrome 黑（`--font-ui`，不分文种）、展示衬线（`--font-disp`，唯 wordmark 与展示数字）、mono（`--font-mono`，唯真数据：数、日期、计数、百分比、代码、路径）（d326a9e，收尾 7f23bdb：96 处审计，53 留 mono、43 转轨）。
- **判准**：紧邻数字的全大写类目标签是描述数据的 chrome，不是数据——标签转轨，数字留 mono。
- **既判力**：新页面不得因「文字是中文」而选 `--font-zh`；内容/chrome 之别唯一有效。

### 判例四 · 朱唯人裁（accent 声部）

- **裁定**：accent 退出评分行、错题、警示等一切语义场景；只司鈐印身份、当前位置（due、进度、streak、active tab）与人裁之痕（v1.4.0）。
- **既判力**：accent 不作按钮底色、不作装饰块、不入语义警示；声部扩张走复议。
- **递修（R2，2026-08-09，记-25）**：锚色由铜 `#B86A30` 换为砖红 `#af3a2c`（反解自 Dystopia 色板）。**职司一字不改**——本条所裁者是 accent 之司，非其色；旧条文「直取品牌 icon 实色」之前提随铜退役而失效，然裁定本身不因换色而动摇。日后读簿者勿以为本判例整条被推翻。
- **既判力之实证（R2 两见）**：`StructureTree` 四色堆叠条以 accent 承「中档熟练度」、`DeckDetail` 熟练度点与 meta 行同病——皆本条所禁而潜行至今，R2 归位。`ConfirmSheet` 非破坏之确认钮曾以 accent 作底，同此，改归墨。

### 判例五 · 会话直排

- **裁定**：L2 复习/练习会话内容直排 `--bg`，去卡套卡；「答」朱印替 ANSWER 角标（v1.4.0）。
- **既判力**：会话类全屏页不引入容器卡；卡唯用于「叶」义成立处。

### 判例六 · 大轮必拆笔

- **裁定**：跨页面重定调不得单笔提交。M1b 首笔（57177e9）单笔回迁，致三页遗漏、越界 CTA、tab bar 超厚近三成，事后 9 笔修复方齐。
- **判准**：一轮触及三页以上者，按页或按母题拆笔，中途至少一次独立 review 检查点。
- **既判力**：本轮刻版递修适用。

### 判例七 · 影刻漂移即讹

- **裁定**：`docs/design-tokens.md` 与 `design/handoff/phase-b-full.html`（== `docs/index.html`，逐字节同）所记为 Phase B 暖调值（bg hue 90、accent oklch 38、radii 4–16px、有影），底本已于 eb8d39d 转冷中性（bg hue 250、accent `#B86A30`、radii 2–10px、全零影）。影刻与底本不同步而行世，以讹论：design-tokens.md 降格为指针件；design/ 各 HTML 归档为史料；另立漂移预防——影刻必署非权威与牌记，死校核牌记。
- **既判力**：凡由底本派生之文档、原型、书影，无牌记者不入验收。

### 判例八 · 钮必有功

- **裁定**（主令，2026-08-09）：一切按钮皆须承载真实会用到的功能。装饰钮、走不通的钮、与他处重复的入口，一律删。
- **判准**：逐钮问三事——① 按下去发生什么？② 这件事用户真会做吗？③ 同屏或上一级是否已有同一入口？三问有一答不出或答「否」者删。
- **据何**：成熟单品之标准。屏上每多一个不被按的钮，主行动的份量就少一分；焦点稀释是本轮首页三病之一（另二为指标通胀、动作无态）。
- **既判力**：本判例适用于一切新增与改版页面；既有页面按屏清查，随其重构之笔行。删钮亦是改，须入记——不得以「顺手删了」了事。
- **复议门槛**：欲留某钮者，须书面答上列三问，附使用场景，不得以「以后可能有用」为由。

## 校勘记（R2 轮：主链路重定调 + 声部换刻，2026-08-09 起）

### 记 2026-08-19-41 · 一级入口由模块改为今日路径

- **改何**：一级导航由「练习／记忆／阅读」改为「今日／资料／活动」。原三模块不删，降为资料页内的单选分类；旧 `?tab=quiz|flashcard|reading` 深链仍直达对应分类。新增 `derive/today.todayJourney()` 统一读取三模块中断现场、到期卡片、错题与未读完文档，按「最近中断 → 到期复习 → 错题订正 → 未读完文档」裁出唯一主行动；今日页只排一条主行动与三段路径，不另造指标卡。复习完成后仍先接下一到期卡组；无同模块下一步时接订正或阅读。练习全对后接复习或阅读；有错仍先走既有错题回顾。活动升为一级入口，撤返回箭头并保留底栏。
- **据何**：三模块各自已有焦点行与场景恢复，但旧一级导航要求用户先判断应进哪一模块，产品正面仍是工具集合。现有真实数据已经足以推导下一步，无须改存储或编造时间估算。Apple design 所取仅为即时按压反馈、空间连续与克制；不取 native 控件外观、玻璃整面或活动圆环（家2、判例一、记-31 既判力不动）。
- **判准**：首屏只回答「现在做什么」；中断现场优先且多个现场按真实保存时刻排序。主行动只有一处，路径行只报状态，不增三枚 CTA。资料分类保留全部原功能与旧深链。数据区静止；动效频率门判首页为每日数次、目的为状态指示与避免初显跳变，故只让焦点区以 `opacity + translateY`、`--motion-mid` 入场一次，列表、热力与路径数据皆不动。底栏与主按钮只作 `--motion-quick` 按压反馈；reduced-motion 继续由底本全局门接管。不采弹簧、bounce、整页滑屏与装饰 stagger。
- **四问**：声部预算——accent 只标当前一级入口与「接下来」，未扩司；行款——手机单栏、宽屏仍止 `--col-list` 480；记号——路径点只表当前／已清／随后三态，非装饰；态——无资料、今日已清、中断、待处理、旧深链、明暗纸与 reduced-motion 均有落点。
- **证据**：新增 `todayJourney` 四测，覆盖最新中断、三级回落、今日已清与失效现场；完整 `npm run check` 通过（28 文件、211 测试，四门 0 FAIL，构建成功）。390×844 明暗两纸与 768×1024 明纸浏览器目验：底栏无覆盖、活动页可滚至底、宽屏内容栏实测 480px；资料三分类 `aria-pressed` 与一级底栏 `aria-current` 对读一致。控制台除既有 React Router v7 future-flag 警告外无错误。

### 记 2026-08-20-42 · 返回服从目录，不服从偶然历史

- **改何**：`resolveParent(pathname, search, returnTo)` 立为返回契约单源。三类资料对象各回其资料分类；复习、浏览、练习与解答会话先回所属对象；阅读器有文集即回文集、无文集才回阅读资料；导入与 AI 制作指南按真实 tab／目标归源，卡组定向制作指南透传 deckId。搜索、设置等横切页可承接调用方显式传入的站内 `returnTo`，但拒绝外部 URL、协议相对 `//` 与非字符串值；无父级之根不造返回，未知深链保守归根。首页进入搜索／设置、今日路径进入会话／导入时均显式携来源。所有自由字符串在生产 path／query 时先编码，故含 `&`、`/`、`?`、`#` 的科目与集合名不截断目录。所有 icon-only 返回与更多钮补齐可及名。
- **据何**：浏览器历史只回答「刚从哪里来」，不回答「此页在产品里属于哪里」；刷新、深链与跨模块完成后若只用 `navigate(-1)`，同一页会随机退出应用、回错模块或落入空历史。目录关系须由产品定义，临时来源只可在可信站内范围内覆盖。
- **判准**：对象页与会话页的上一级由路径结构唯一决定；横切页优先回显式来源；返回动作不依赖历史是否存在。可见后退图标必须有读屏名称，视觉与路由契约各自独立成立。
- **证据**：父级纯函数矩阵 32 测覆盖三级资料、会话、reader 文集、导入 tabs／deckId、制作指南上下文、恶意来源与未知深链；生产路由构造另以三测锁住 subject 斜杠、无 chapter 的 section 与含 `&/#` 的 qid。390×844 实页点验：资料练习→设置→返回仍在练习分类；题库对象返回精确落 `?view=materials&kind=quiz`；阅读器返回精确落所属文集。

### 记 2026-08-20-43 · 阅读正文写定后方可称成功

- **改何**：阅读文档增删改为可等待、可失败的 Promise 契约。新增先等 IndexedDB 正文事务 `complete`，再公开带 `hasBody` 的 localStorage 元数据；元数据失败则补偿删除正文。删除依次清正文、高亮、书签与元数据，任一步失败均抛出带 operation／stage／cause／rollbackFailures 的 `ReadingStorageError`，并按 id 合并恢复快照。文档突变串行化，且 await 之后重读元数据，避免等待正文时并发更新被陈旧快照覆盖。`idbSet`／`idbDel` 只在事务完成时返回真；所有直接调用方均 await，并有 ref 单飞闩锁、disabled／aria-busy 与进行中文案；成功后才刷新或跳转，失败保留输入并显式告知。系统返回离页后的旧 Promise 不再 toast 或夺回路由；正文失败会回收本次临时文集。示例包的并发请求合并为同一 Promise，先写阅读再写同步模块。旧内嵌正文迁移也只在 IDB 确认后删除唯一副本。
- **据何**：内存或 request `onsuccess` 不等于事务已经写定；界面先报成功、磁盘后失败，是数据工具最重的失信。阅读正文与元数据虽跨 IndexedDB／localStorage，不能拥有真正跨库事务，仍须把可观察成功点推迟到最晚的已确认步骤，并以补偿与错误面收窄裂缝。
- **判准**：正文未确认则文档不得公开；删除未确认则不得静默；同一动作 pending 时不可重入，离页后的完成不得改写新页面。并发突变不互相覆盖。突发进程强杀的跨存储窗口、旧 `deleteCollection` 的 fire-and-forget、`idbGet` 对缺值／读取失败的同形，以及 backup import／merge 先写 localStorage 后写 IDB 的跨存储原子性，明确留账，不伪称绝对闭环。
- **证据**：失败注入、关联清理、并发新增、删除回滚、pending 重入、unmount stale completion、临时文集回收、示例并发合并、迁移保本、IDB abort／error／不可用及「正文待写期间同步更新不丢失」均有回归测试；统一门禁 35 文件、270 测试全绿，四门 0 FAIL，production build 成功。

### 记 2026-08-20-48 · 目录叶自带题型，空域不是展示词

- **改何**：`SetDetail` 的选择题／解答题筛选改从真实题目集派生，同一范围同时约束章节行、展开子项、收藏计数与结构视图；收藏不再伪装成章节筛选，仍归顶栏唯一入口。结构视图按 chapter → section → type 成树，混合范围拆成两枚明确题型叶，纯解答叶不再因同科另有选择题而误入选择会话。无章节／无小节只在界面显示「未分类」，路由以显式 `chapter=`／`section=` 保存真正空域；会话页、引擎与中断恢复以 `has()` 区分「未给范围」与「范围为空」。
- **判准**：筛选必须改变用户实际可进入的对象，不只隐藏父行；任一叶的目标由叶自身题型决定，不由全科库存猜测。展示文案不得反写为数据查询值。可及语义取原生嵌套列表与 disclosure button；没有方向键、roving focus 等完整树键盘模型时，不冒充 ARIA tree。折叠组即使隐藏仍留在 DOM，使 `aria-controls` 始终有实指。
- **证据**：回归覆盖 all／choice／review、章节子项、筛选后收藏计数、mixed section 拆叶、pure review、空 chapter／section 的 route 与 engine 精确匹配，以及原生列表、展开状态、控制目标与叶按钮。独立审校先否决半成品 `role=tree` 与跨题型收藏泄漏，递修后方准入；统一门禁 40 文件、292 测试全绿，四门 0 FAIL，production build 成功。

### 记 2026-08-20-49 · 会话位置一处足矣，图标须可称名

- **改何**：选择题与解答题会话的题目位置统一只留在卡面上方 `.rv-meta`；顶栏与卡角重复的 `x / y`、序号撤下。卡角继续标「选择」「解答／参考答案」，正确率、题型、完成状态等异义信息不动。选择题页收藏与更多两个 icon-only 按钮补动态／固定可及名；解答页已有同名契约，不重复铺设。

- **证据**：两类会话组件回归锁住 `.rv-meta` 的唯一位置读数、顶栏与卡角不再复述，以及收藏／更多按钮的可及名；统一门禁 41 文件、294 测试全绿，四门 0 FAIL，production build 成功。

### 记 2026-08-20-50 · 浮层接管焦点，也须归还现场

- **改何**：详情与两类练习页的更多操作由半成品 `menu/menuitem` 降为命名操作组与原生 list／link／button；共享 `useOverlayFocus` 负责打开聚焦首项、Tab 双向圈闭、Escape 退出与关闭后回原触发器。幕布移出顶栏的 fixed containing block，统一为 `.menu-backdrop`，并从宽屏内容栏收束规则中排除。菜单打开时正文、固定操作区与非 overlay 顶栏控件真正 inert，标题退出可及树。`ConfirmSheet` portal 至 `body`，对应用根暂置 inert，安全的取消动作先得焦点；菜单动作先卸载操作组，再以显式 `returnFocus` 打开确认层，避免两套 focus trap 并存。
- **判准**：overlay 的完整性不由 z-index 单独成立；须同时满足空间覆盖、焦点所有权、键盘退出、幕后隔离和现场归还。未实现 Arrow/Home/End 与 roving focus 时不得声称 ARIA menu。关闭幕保留可及名称，既可点击也可由读屏称名；其不进入 Tab 环，不替代 Escape。全视口幕不得受 `--col-current` 限宽。
- **证据**：组件回归覆盖四菜单 focus-in、Tab／Shift+Tab、Escape、scrim 点击、幕后 inert、菜单 action 可聚焦、菜单→dialog 无双 trap、确认层安全焦点／Escape／backdrop／断开 trigger，以及 CSS 两类 page shell 对 `.menu-backdrop` 的排除；独立审校发现并封住宽屏幕布被内容栏限宽之讹。统一门禁 43 文件、304 测试全绿，四门 0 FAIL，production build 成功。

### 记 2026-08-20-51 · 密图另给等价路径，小钮不得以密为由失尺

- **改何**：Reader 的字号、行距、边距由六枚 24px 小钮重排为三列 stepper；每组有标签、当前值与两枚 44×44px 原生按钮，达到上下限即 disabled。Activity 的 90 日热力图保留 14px 视觉密度但整块退出可及树，不制造 90 个 Tab 停点；另设一枚 44px 原生日期 select，视觉点击与键盘／读屏选择共用 `selectedDate`，常驻 `aria-live="polite"` 详情随之更新。
- **判准**：高密数据图不靠重叠 hitbox 伪造 44px，也不把每个像素格都变成键盘债；须提供同数据、同状态、同结果的清楚等价路径。频繁调节控件仍须有真实 44px 命中面、独立名称与边界禁用。窄屏以重排解决，不以横滚或缩小目标解决。

### 记 2026-08-09-31 · 版面落实物：焦点行、行即入口、关系式

原型所定四条（版1 焦点行、版2 主行动唯一、版3 行承载、版4 动作有态）逐屏落地。此记只录**判准与所拒**，逐屏之改见提交。

- **版1 之根不在版面，在契约**。旧 `HeroSection` 之 `metrics[]` 三列 API 是指标通胀的**制度**：给三个格，页面就会去凑三个数，凑出来的多半是「总数」这类不支持决策之量。故新件 `FocusHeader` 只收「一数、一句、一去处」——凑不出第二个数就是对的。同理 `derive.todayFocus()` 刻意不返回「总数」「今日已复习」：若只改版面而不改契约，下一个页面又会把它们取回去。

- **据何**：真机预览目验。70%／.145 折算 `#eb7867`，实机读作**鲑鱼粉**而非砖红——明纸 `#af3a2c` 之红意在暗纸上因抬明度而流失。降一档明度、补一档彩度收回红意（`#e2604f`）。
- **判准**：暗纸取值不得以「明纸值加明度」推导。同一 hue 在两纸上的**知觉**不同，须以实机所见裁，再以门校底线。此前 `--accent` 于暗纸为 hex 字面量 `#D9945E`（记-04 跨层异文），恰是无人以 oklch 推导过它的证据。
- **证据**：门三重跑，暗纸 accent 四对 5.53／5.25／4.78／4.78 全 PASS；书影见预览（375×812，dark）。
- **待验**：Android 真机（明纸砖红于低 DPI 之小字号、暗纸此值于 OLED 之观感）随验证批同做。

### 记 2026-08-09-28 · 门三之限度：校 token 不校落点

- **所发**：本轮全部对比度失败，**无一是门看得见的**。门三校 19 对 token 对 token，而三类失败皆在落点——① `opacity` 混算（评分行副标 `.k` 混后实测 2.39–3.72）；② token 被用作它从未配对过的底（`pending` 态拿 `--ink-4` 当底，标签 2.15）；③ 四级墨排字（`--ink-4` 作轴标、计数、meta，明 2.15／暗 2.07，连 INFO 之 3.0 亦不及）。
- **改何**：门三补入四类落点对（见 design-kanli §九）；`--ink-4` 之职司在底本写死为「线、轨、禁用之形，不入文字位」。
- **判准**：可判定者入门，不可判定者入常法文字。门只报离合，不定是非——落点之校仍属活校，凡称「已过对比度」者须指明所校为何对。
- **同题三见**：记-22 未验而断言、记-23 验了错的东西（只验公式不验落点）、本记门本身只验了错的东西——**三见**。故不止于修值，而改门之覆盖面，并在 §九 明书门之限度。

### 记 2026-08-09-26 · danger 之司自三收一

- **改何**：`--danger` 由洋绯改墨阶 `oklch(38% .014 240)`，另立 `--danger-critical` 真红（守底本原洋绯值）承「有后果之动作」。落点逐个归位：评分「重来」、重来计数、左滑重来浮标、破坏性确认钮与其告白、删数据/批删/删卡诸钮 → 真红；错误提示、错题标记、顽固卡、弱卡 → 墨阶并补非色线索。
- **据何**：主令择甲案（accent 取色板真值）而问「danger 可否退墨阶」。danger 原载三司（重来、错、destructive），退墨阶则三司皆失色，评分行「重来」与「良好」将塌成一档（雠实测两底相差 0.9% 明度、字色全等）。
- **判准**：按**「有无后果」**划线，不按屏之轻重划线——将要失去或刚失去某物者取真红，只是被告知某处不对者取墨阶。此判准可一句陈述故可入簿；「这屏不重要故不给色」不可陈述故不取。
- **连带**：「弱」退出 danger。弱是熟练度序列末档，非错、非重来、非 destructive——旧版 accent 越界作中档（判例四）方除，若再让 danger 越界作末档，是同型之讹换个声部重犯。熟练度遂收为**熟练度计**（一记一义：已稳固之比例，墨阶两段，充填对轨 7:1），四色堆叠退役——其四档在 3px 上本不可辨（暗纸相邻实测 稳/中 2.99、中/弱 1.21）。
- **证据**：明暗各 25 对 required 全 PASS；`bg / danger-critical` 一对系新入门——恒白作语义底上之字在暗纸只 2.98，改取 `var(--bg)` 後明 6.70／暗 6.47。

### 记 2026-08-09-25 · 声部换刻（Dystopia）

- **改何**：`--accent` 由铜 `oklch(50% .122 55)` 换砖红 `oklch(51.5% .155 30)`；底盘灰阶 hue 250 微移 240，值据色板反解（纸 `#F4F5F6`、界 `#DDE1E4`、次墨 `#565C5F`、墨 `#2A2D2E`）；`--ink-3` 明 54→53、暗 61→64；暗纸 `--accent` 旧为 hex 字面量 `#D9945E`（跨层异文，记-04），归 oklch。品牌资产（splash、launcher icon、启动底色）三生成器之色一并归底本，并清 legacy icon 之暖调 linearGradient（渐变属国讳，且其二色与现行底盘无一相干）。
- **据何**：主令（Dystopia 色板，「采为新声部替换铜」）。
- **判准**：accent 作小字排（due 数、streak、位置记），故取最严消费者 4.5:1 於 `--bg-card`——实测 6.08，色板真值不必再压。曾拟压至 `0.115` 彩度以躲 danger，danger 既退墨阶（记-26），此让步失据，撤。
- **拒准同档**：曾拟将 danger 提彩至 `oklch(46% .19 8)` 以与 accent 拉开——**实测出 sRGB 色域**，钳到品红 `#a60043`，且在 P3 屏与 sRGB 屏所见不同色，撞色距离随设备浮动。立论自败，撤。**顺立一门之缺**：`wcag.mjs` 已算出 `outOfGamut` 而 `collate.mjs` 从不报它，出域之值可一路进底本——补此门列 roadmap，阴性对照之架已现成。
- **拒准同档（乙案）**：评分行全墨（danger 只剩「删除」一司）主令未取。理由：评分行是全应用按得最频繁、也是唯一四档同时在屏之处，色在此买到的识别速度值其预算；墨阶阶梯调至最好，「困难」与「良好」相邻两档仍只差一级描边。

### 记 2026-07-25-23 · 结构改法：级由变量择，消费唯一
